# FlashCard AI Coding Challenge

A browser-based flashcard study app. Leveraging AI coding assistants to move faster while reviewing and refining output.

## Reflections

- AI saved time on the boilerplate code and left time for me to test and tweak the code.
- A code snippet I refactored was the search filter was written out separately wherever the visible cards were needed. I put it into one help function so the card area and the navigation both use the same logic.
- Vague prompts gave generic layouts name the exact constraints worked better. Asking it to use the same class names in the HTML and CSS also cut down the inconsistencies.
